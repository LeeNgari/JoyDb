# Phase 5.1 (Redo): Tombstones & Stable Row IDs — Definitive Plan

This is the **corrected and final** plan for migrating JoyDB from volatile array-index storage to immutable Record IDs (RIDs). It incorporates every lesson learned from the failed first attempt, every bug we discovered, and every benchmark regression we measured.

> [!IMPORTANT]
> **This plan is designed to be followed step-by-step, in order, with compilation checks between phases.** Every decision is explained with a "why" so there is zero guesswork.

---

## Lessons Learned from the Failed First Attempt

Before diving into the plan, here is what went wrong last time and exactly how this plan avoids each mistake.

### Mistake 1: The Dual-Sync Compatibility Crutch

**What happened:** To avoid breaking tests that manually set `table.Rows = []data.Row{...}`, we kept the old `Rows` slice alongside the new `RowsByRID` map and added bi-directional sync methods (`SyncRowsUnsafe`, `EnsureRowsByRIDPopulatedUnsafe`). These triggered on every `INSERT`, `UPDATE`, and `DELETE`, re-introducing the exact $O(N \log N)$ sorting cost we were trying to eliminate.

**Lesson:** Never maintain two parallel data structures "for compatibility." The whole point of Phase 5.1 is to replace the slice. Keeping it alongside the map defeats the purpose.

**This plan's fix:** We rip out `Rows []data.Row` from the `Table` struct in Phase 1 with zero compromise. All tests will be fixed to use `InsertReplay()` in Phase 7. We accept temporary test breakage.

---

### Mistake 2: Non-Reentrant RWMutex Deadlocks

**What happened:** Public methods like `SelectAll()` acquired `t.RLock()`, then called helper methods like `LiveRows()` and `RowByRID()`, which *also* tried to acquire `t.RLock()`. Go's `sync.RWMutex` deadlocks if a goroutine holds `RLock` and a writer is waiting for `Lock` — the second `RLock` will block forever.

**Lesson:** In Go, you cannot nest `RLock()` calls on the same mutex when writers may be waiting. The locking hierarchy must be strict: **public methods lock; internal `*Unsafe` methods never lock.**

**This plan's fix:** Phase 3 establishes a strict rule and audits every method:
- Public methods (`SelectAll`, `Select`, `SelectByIndex`, `LiveRows`, `LiveRowCount`, `RowByRID`, `Insert`, `Update`, `Delete`) acquire the lock, call *only* `*Unsafe` internal helpers, then release.
- Internal helpers (`LiveRowsUnsafe`, direct `t.RowsByRID[rid]` access) never touch the mutex.

---

### Mistake 3: TOCTOU Map Panics

**What happened:** To "fix" the deadlock, we dropped `RLock()` before accessing `t.RowsByRID`. Concurrent reads and writes to a Go map without synchronization cause an unrecoverable runtime panic (`fatal error: concurrent map read and map write`).

**Lesson:** You can never access a shared map without holding a lock. The fix for deadlocks is not to remove locks — it's to fix the locking hierarchy.

**This plan's fix:** Every access to `t.RowsByRID` happens inside a lock. Period. The hierarchy fix in Mistake 2 eliminates the need to drop locks.

---

### Mistake 4: Snapshot Isolation Violation

**What happened:** `Update()` mutated `row.Data[col] = val` directly on the map value. Because `Row.Data` is a `map[string]interface{}` (a reference type), this mutation was visible to all concurrent readers holding references to the same row.

**Lesson:** Go map values are not addressable. When you write `row := t.RowsByRID[rid]; row.Data[col] = val`, you are mutating the underlying map through the `row` variable's `Data` pointer. You must deep-copy before mutating.

**This plan's fix:** Phase 3 specifies: `Update()` must `row.Copy()` before applying mutations, then re-assign: `t.RowsByRID[rid] = newRow`.

---

### Mistake 5: The 23x-45x Full-Scan Regression

**What happened:** `LiveRowsUnsafe()` was implemented as:
1. Iterate `RowsByRID` map → collect non-deleted rows (each deep-copied via `row.Copy()`)
2. `sort.Slice()` the result by `RID` for deterministic ordering

For a 10,000-row table, every `SelectAll()` call triggered 10,000 map lookups, 10,000 deep-copies, and an $O(N \log N)$ sort. Phase 4 baseline used a simple slice iteration ($O(N)$ with cache locality).

**Benchmark evidence:**
| Benchmark | Phase 4 (baseline) | Phase 5.1 (broken) | Regression |
|-----------|-------------------|-------------------|------------|
| `select_full_scan_1k` | 49,755 TPS | 2,131 TPS | **23x slower** |
| `select_full_scan_10k` | 6,791 TPS | 150 TPS | **45x slower** |
| `select_scan_scaling_10000` | 5,012 TPS | 96 TPS | **52x slower** |

**Lesson:** Deep-copying every row on every scan is catastrophically expensive. The sort is also unnecessary for most callers (SQL has no guaranteed order without ORDER BY).

**This plan's fix:**
1. `LiveRowsUnsafe()` still deep-copies (for safety) but we accept this cost for correctness. The sort is kept for deterministic test behavior but is clearly documented as an optimization target.
2. **Critical future optimization** (noted but not implemented in this phase): Use B+Tree `All()` method to iterate in RID order without sorting. This is $O(N)$ and avoids the sort entirely. The B+Tree leaf linked-list is already in sorted order.
3. The scan regression is acceptable given the massive gains elsewhere (UPDATE: 52→85 TPS = 63% improvement, DELETE: 58→94 TPS = 62% improvement, PK lookups: 2,242→128,927 TPS = 5,650% improvement). The scan regression can be addressed in Phase 5.2 with iterator-based scans.

---

### Mistake 6: Test Migration Chaos

**What happened:** Over 100+ test breakages across 10+ files. Tests directly set `table.Rows = append(table.Rows, row)`, bypassing all engine logic (indexes, RIDs, validation). Fixing them was time-consuming and error-prone because we didn't have a clear migration pattern established upfront.

**Lesson:** Establish the test migration pattern *before* starting, and use a single helper function everywhere.

**This plan's fix:** Phase 7 defines the exact pattern:
```go
// OLD (broken): table.Rows = append(table.Rows, row)
// NEW (correct): table.InsertReplay(data.NewRow(map[string]interface{}{...}))
```
Every test file is listed with its exact migration steps.

## Architecture Overview

### Pre-Phase-5.1 (What You Have After Git Revert)

```
Table struct {
    Rows      []data.Row          // ← Primary storage (volatile array positions)
    PKIndex   *btree.BPlusTree    // PK → array position (int)
    Indexes   map[string]*Index   // value → []int positions
}
```

**Problem:** DELETE at position 3 shifts all subsequent rows, invalidating every index entry. Requires full $O(N \log N)$ index rebuild.

### Post-Phase-5.1 (What We're Building)

```
Table struct {
    RowsByRID      map[int64]data.Row    // RID → Row (primary storage)
    PKIndex        *btree.BPlusTree      // PK → RID (int64)
    Indexes        map[string]*Index     // value → []int64 RIDs
    NextRID        int64                 // Monotonic counter
    TombstoneCount int                   // For vacuum threshold
}
```

**Solution:** DELETE marks `row.Deleted = true` and removes the single index entry. No other rows move. No other indexes change. $O(\log N)$ for B+Tree, $O(1)$ for hash.

```go
type Row struct {
    Data    map[string]interface{}
```

**Why `RID` is not in `Data`:** RID is a physical-layer concept (like a disk page address). It is invisible to SQL queries. Storing it in `Data` would expose it through `SELECT *` and corrupt the logical data model.

**Why `Deleted` is a field, not map removal:** Tombstoned rows must remain in `RowsByRID` temporarily so that:
1. Concurrent readers holding stale references see a consistent state.
2. WAL recovery can replay deletes as tombstones (replay is idempotent).
3. The vacuum can reclaim them in batch without disrupting ongoing operations.

**Additional changes:**
1. Add `NewRow(data map[string]interface{}) Row` constructor that initializes `RID: 0, Deleted: false`.
2. Update `Copy()` to include `RID` and `Deleted`.
3. Update `Serialize()`: Write `RID` (8 bytes) + `Deleted` (1 byte) before field data.
4. Update `Deserialize()`: Read `RID` + `Deleted` as first 9 bytes.

> **Serialization format is NOT backward-compatible.** Old snapshots use the V1 format (no RID, no Deleted). This is acceptable because:
> 1. We are reverting to the pre-Phase-5.1 commit, so any snapshots created during the broken Phase 5.1 will be discarded.
> 2. This is a new project — there is no production data to migrate.
> 3. There will be no need for backward compatibility ever. If backward compatibility is ever needed, we can add a version byte (already present in the snapshot header as `SnapshotVersion`).

#### 3b. Locking Hierarchy (THE CRITICAL RULE)

> [!CAUTION]
> **Rule: Public methods acquire the lock. Internal `*Unsafe` methods NEVER touch the mutex. No public method may call another public method.**
>
> This rule alone prevents all deadlocks from Mistake 2. Violating this rule is the #1 cause of deadlocks in Go concurrent code.

The methods are split into two tiers:

**Tier 1 — Public (acquires lock):**
| Method | Lock Type | Calls (Unsafe only) |
|--------|----------|-------------------|
| `LiveRows()` | `RLock` | `LiveRowsUnsafe()` |
| `LiveRowCount()` | `RLock` | inline loop over `RowsByRID` |
| `RowByRID(rid)` | `RLock` | inline `t.RowsByRID[rid]` |
| `SelectAll(tx)` | `RLock` | `LiveRowsUnsafe()` |
| `Select(pred, tx)` | `RLock` | `LiveRowsUnsafe()` |
| `SelectByIndex(col, val, tx)` | `RLock` | inline PKIndex + RowsByRID |
| `Insert(row, tx)` | `Lock` | `validateRow()`, `MarkDirtyUnsafe()` |
| `Update(pred, updates, tx)` | `Lock` | inline iteration, `MarkDirtyUnsafe()` |
| `Delete(pred, tx)` | `Lock` | inline iteration, `MarkDirtyUnsafe()` |
| `Vacuum()` | `Lock` | `VacuumUnsafe()` |

**Tier 2 — Internal/Unsafe (NEVER acquires lock):**
| Method | Purpose |
|--------|---------|
| `LiveRowsUnsafe()` | Iterate RowsByRID, skip tombstones, sort by RID, return copies |
| `MarkDirtyUnsafe()` | Set `t.Dirty = true` |
| `VacuumUnsafe()` | Delete tombstones from map |
| `validateRow(row)` | Check NOT NULL, types |
| `validateType(col, val, type)` | Type checking |
| `rebuildIndexesUnsafe()` | Cold-path index rebuild (only for snapshot load) |
| `InsertReplay(row)` | WAL recovery (single-threaded, no lock needed) |
| `InsertReplayRID(row)` | WAL recovery with explicit RID |

#### 3c. Method-by-Method Implementation

##### `LiveRowsUnsafe()` — The Most Sensitive Method

```go
func (t *Table) LiveRowsUnsafe() []data.Row {
    if t == nil || t.RowsByRID == nil {
        return nil
    }
    var result []data.Row
    for _, row := range t.RowsByRID {
        if !row.Deleted {
            result = append(result, row.Copy())  // Deep copy for isolation
        }
    }
    // Sort by RID for deterministic ordering (test stability)
    sort.Slice(result, func(i, j int) bool {
        return result[i].RID < result[j].RID
    })
    return result
}
```

**Why deep copy:** Without it, callers hold references to map values. A concurrent `Update()` or `Delete()` would mutate those references, violating snapshot isolation (Mistake 4).

**Why sort by RID:** Go maps have non-deterministic iteration order. Without sorting, `SelectAll()` returns rows in random order on every call, causing test flakiness. The sort gives deterministic behavior equivalent to the old slice ordering.

**Known cost:** This is $O(N \log N)$. The benchmark shows 23x-45x regression on full scans. **This is accepted as a correctness-over-performance tradeoff.** Optimization path for Phase 5.2: use `PKIndex.All()` to iterate in PK order (already $O(N)$ via leaf linked-list), then look up each RID in the map.

##### `Insert(row, tx)` — Full Implementation

```go
func (t *Table) Insert(mutRow data.Row, tx *transaction.Transaction) error {
    row := mutRow.Copy()  // Prevent caller mutation
    t.Lock()
    defer t.Unlock()

    if t.RowsByRID == nil {
        t.RowsByRID = make(map[int64]data.Row)
    }

    // 1. Handle auto-increment PK
    // [same logic as current — find autoIncCol, generate nextID, etc.]

    // 2. Validate the row
    if err := t.validateRow(row); err != nil {
        return err
    }

    // 3. Check unique/PK constraints via hash indexes
    for colName, idx := range t.Indexes {
        if val, exists := row.Data[colName]; exists && idx.Unique {
            if _, found := idx.Data[val]; found {
                return &errors.ConstraintError{...}
            }
        }
    }

    // 4. Assign new RID
    if t.NextRID == 0 { t.NextRID = 1 }
    rid := t.NextRID
    t.NextRID++
    row.RID = rid
    row.Deleted = false

    // 5. Update PKIndex
    if t.PKIndex != nil {
        pkCol := t.Schema.GetPrimaryKeyColumn()
        if pkCol != nil {
            if pkVal, exists := row.Data[pkCol.Name]; exists {
                if err := t.PKIndex.Insert(pkVal, rid); err != nil {
                    return &errors.ConstraintError{...duplicate PK...}
                }
            }
        }
    }

    // 6. Update hash indexes
    for colName, idx := range t.Indexes {
        if val, exists := row.Data[colName]; exists {
            idx.Data[val] = append(idx.Data[val], rid)
        }
    }

    // 7. Store in map
    t.RowsByRID[rid] = row

    // 8. Mark dirty
    t.MarkDirtyUnsafe()
    return nil
}
```

##### `Update(pred, updates, tx)` — With Isolation Fix

```go
func (t *Table) Update(predicate func(data.Row) bool, updates data.Row, tx *transaction.Transaction) (int, error) {
    t.Lock()
    defer t.Unlock()

    // 1. Validate update columns exist in schema
    // [existing validation code]

    // 2. Collect matching RIDs first (avoid mutating map while iterating)
    var matchedRIDs []int64
    for rid, row := range t.RowsByRID {
        if !row.Deleted && predicate(row) {
            matchedRIDs = append(matchedRIDs, rid)
        }
    }

    // 3. Apply updates
    count := 0
    pkCol := t.Schema.GetPrimaryKeyColumn()

    for _, rid := range matchedRIDs {
        row := t.RowsByRID[rid]
        newRow := row.Copy()  // CRITICAL: Deep copy before mutation (Mistake 4 fix)

        for colName, newValue := range updates.Data {
            oldValue := newRow.Data[colName]
            if oldValue == newValue { continue }

            // Validate type
            // [type validation code]

            // Update PK index if PK column changed
            if pkCol != nil && pkCol.Name == colName {
                if t.PKIndex != nil {
                    t.PKIndex.Delete(oldValue)
                    if err := t.PKIndex.Insert(newValue, rid); err != nil {
                        _ = t.PKIndex.Insert(oldValue, rid)  // Rollback
                        return 0, &errors.ConstraintError{...}
                    }
                }
            }

            // Update hash indexes
            if idx, exists := t.Indexes[colName]; exists {
                // Remove RID from old value's list
                if oldList, found := idx.Data[oldValue]; found {
                    var newList []int64
                    for _, r := range oldList {
                        if r != rid { newList = append(newList, r) }
                    }
                    if len(newList) == 0 {
                        delete(idx.Data, oldValue)
                    } else {
                        idx.Data[oldValue] = newList
                    }
                }
                // Add RID to new value's list
                idx.Data[newValue] = append(idx.Data[newValue], rid)
            }

            newRow.Data[colName] = newValue
        }

        t.RowsByRID[rid] = newRow  // Re-assign the copy
        count++
    }

    if count > 0 { t.MarkDirtyUnsafe() }
    return count, nil
}
```

##### `Delete(pred, tx)` — Tombstone Instead of Splice

```go
func (t *Table) Delete(predicate func(data.Row) bool, tx *transaction.Transaction) (int, error) {
    t.Lock()
    defer t.Unlock()

    // 1. Collect matching RIDs
    var matchedRIDs []int64
    for rid, row := range t.RowsByRID {
        if !row.Deleted && predicate(row) {
            matchedRIDs = append(matchedRIDs, rid)
        }
    }

    // 2. Tombstone each matched row
    deleted := 0
    pkCol := t.Schema.GetPrimaryKeyColumn()

    for _, rid := range matchedRIDs {
        row := t.RowsByRID[rid]

        // Mark as deleted (tombstone)
        row.Deleted = true
        t.RowsByRID[rid] = row
        deleted++
        t.TombstoneCount++

        // Remove from PK index
        if pkCol != nil && t.PKIndex != nil {
            if pkVal, exists := row.Data[pkCol.Name]; exists {
                _ = t.PKIndex.Delete(pkVal)
            }
        }

        // Remove from hash indexes
        for colName, idx := range t.Indexes {
            if val, exists := row.Data[colName]; exists {
                if rids, found := idx.Data[val]; found {
                    var newList []int64
                    for _, r := range rids {
                        if r != rid { newList = append(newList, r) }
                    }
                    if len(newList) == 0 {
                        delete(idx.Data, val)
                    } else {
                        idx.Data[val] = newList
                    }
                }
            }
        }
    }

    if deleted > 0 {
        t.MarkDirtyUnsafe()
        // Auto-vacuum if tombstones exceed threshold
        if t.TombstoneCount > 10000 {
            t.VacuumUnsafe()
        }
    }

    return deleted, nil
}
```

**Why tombstone instead of `delete(t.RowsByRID, rid)`:** Immediate map deletion would invalidate concurrent iterators. Tombstoning is safe — readers see `Deleted=true` and skip.

##### `SelectByIndex(col, val, tx)` — B+Tree Fast Path

```go
func (t *Table) SelectByIndex(colName string, value interface{}, tx *transaction.Transaction) (data.Row, bool) {
    t.RLock()
    defer t.RUnlock()

    if t.RowsByRID == nil { return data.Row{}, false }

    // Fast path: B+Tree PK lookup — O(log N)
    if t.PKIndex != nil {
        pkCol := t.Schema.GetPrimaryKeyColumn()
        if pkCol != nil && pkCol.Name == colName {
            rid, found := t.PKIndex.Search(value)
            if !found { return data.Row{}, false }
            row, ok := t.RowsByRID[rid]
            if !ok || row.Deleted { return data.Row{}, false }
            return row, true  // No Copy() needed — caller gets a value copy of Row struct
        }
    }

    // Fallback: hash index
    idx, exists := t.Indexes[colName]
    if !exists || !idx.Unique { return data.Row{}, false }

    // Normalize int → int64 for comparison
    if intVal, ok := value.(int); ok { value = int64(intVal) }

    rids, found := idx.Data[value]
    if !found || len(rids) == 0 { return data.Row{}, false }

    row, ok := t.RowsByRID[rids[0]]
    if !ok || row.Deleted { return data.Row{}, false }
    return row, true
```

##### `InsertReplay(row)` / `InsertReplayRID(row)` — WAL Recovery

```go
// InsertReplayRID adds a row during WAL recovery (no validation, no locking).
// Safe because recovery runs single-threaded before the table is live.
func (t *Table) InsertReplayRID(row data.Row) {
    if t.RowsByRID == nil { t.RowsByRID = make(map[int64]data.Row) }

    rid := row.RID
    if rid >= t.NextRID { t.NextRID = rid + 1 }
    t.RowsByRID[rid] = row

    // Update PKIndex
    if t.PKIndex != nil {
        pkCol := t.Schema.GetPrimaryKeyColumn()
        if pkCol != nil {
            if val, exists := row.Data[pkCol.Name]; exists {
                t.PKIndex.Insert(val, rid)
            }
        }
    }

    // Update hash indexes
    for colName, idx := range t.Indexes {
        if val, exists := row.Data[colName]; exists {
            idx.Data[val] = append(idx.Data[val], rid)
        }
    }
}

// InsertReplay assigns a RID if the row doesn't have one, then delegates.
func (t *Table) InsertReplay(row data.Row) {
    if row.RID == 0 {
        if t.NextRID == 0 { t.NextRID = 1 }
        row.RID = t.NextRID
        t.NextRID++
    }
    t.InsertReplayRID(row)
}
```

```go
// rebuildIndexesUnsafe rebuilds all indexes from RowsByRID.
// ONLY called during snapshot load (cold path). NEVER on hot-path DML.
func (t *Table) rebuildIndexesUnsafe() {
    // Clear hash indexes
    for _, idx := range t.Indexes {
        idx.Data = make(map[interface{}][]int64)
    }

    // Rebuild PKIndex
    if t.PKIndex != nil {
        t.PKIndex.Clear()
        pkCol := t.Schema.GetPrimaryKeyColumn()
        if pkCol != nil {
            for rid, row := range t.RowsByRID {
                if row.Deleted { continue }
                if val, exists := row.Data[pkCol.Name]; exists {
                    t.PKIndex.Insert(val, rid)
                }
            }
        }
    }

    // Rebuild hash indexes
    for rid, row := range t.RowsByRID {
        if row.Deleted { continue }
        for colName, idx := range t.Indexes {
            if val, exists := row.Data[colName]; exists {
                idx.Data[val] = append(idx.Data[val], rid)
            }
        }
    }
}
```
